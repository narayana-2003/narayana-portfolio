# Narayana Portfolio Website

A professional responsive portfolio based on the provided resume.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation, reveal animations and current year

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the `#` GitHub and LinkedIn links in `index.html` with your real profile URLs.
2. Add project repository/demo links if available.
3. Optionally add a profile photo and downloadable resume button.
4. Publish with GitHub Pages, Netlify, or Vercel.
